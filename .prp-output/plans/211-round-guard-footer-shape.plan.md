## Why a re-plan

R1 (head f7308983) and R2 (head d09a2668, run 20261024T140029Z-c5aa275b, comment 6385122310) both found an
Important in the same family: a footer that is *almost* a review footer is silently ignored instead of refused.
R1's fix matched one more spelling. R2 found 4 more that slip through: reversed word order, missing colon,
"Generated by:" with a space, and a footer split over two lines, so the comment's last line is only the
`prp-review-agents v… run=… pass=…` tail. Patching spellings one at a time does not converge, so this plan
defines the footer shape as a grammar and tests that grammar against real data.

## Input (from the caller, PR-B #212)

`gh api repos/{owner}/{repo}/issues/{N}/comments --paginate --jq '.[].body | rtrimstr("\n") | split("\n") | last'`
gives one line per comment: that comment's LAST line. A trailing `\r` can survive.

## Real-data sample (Real inputs first)

`~/tmp/rg-lastlines-sample.txt`: 1255 real last lines from 75 PRs (15 each in prp-framework, soul-orchestra, ops,

  286 OTHER. No false refusal on any real line.

## Invariant

Invariant: every stdin line is classified into exactly one of EXACT (matches RUN_RE, counted), SHAPED (footer-shaped
but not exact, refuses with exit 2) or OTHER (ignored), and every line that carries a footer's identifying parts —
the `generated … by` + `prp-review-agents` pair in either order, a line that starts with the `prp-review-agents v<digit>`
tail, or a `run=<timestamp-id>` together with `pass=` — is EXACT or SHAPED, never OTHER. So a mangled footer can
never lower the count.

Out of scope (stated, not hidden): a line with none of those parts (for example only `pass=code-reviewer`) carries
nothing that ties it to a review run, so it is OTHER. The script's header comment says so.

## The change (scripts/review/round-guard.sh only, plus its bats file)

Replace the current line 33 comment + line 34 `elif` with exactly this (after `RUN_RE=` add the two variables):

```bash
RUN_RE='^Generated-by: prp-review-agents v[^ ]+ run=([0-9]{8}T[0-9]{6}Z-[0-9a-f]{8}) pass=[a-z-]+( tier=trivial)?$'
# Footer shape, matched on the lower-cased line. A line with a footer's identifying parts that is not an exact
# footer refuses (exit 2): the "generated by" + "prp-review-agents" pair in either order (any 0-3 separator chars),
# the "prp-review-agents v<digit>" tail at line start (a footer split over two lines), or run=<id> together with
# pass=. L2 markers and prose that cite run ids have none of these, so they stay ignored.
SEP='[^a-z0-9]{0,3}'
SHAPE_RE="generated${SEP}by${SEP}prp-review-agents|prp-review-agents${SEP}generated${SEP}by|^[^a-z0-9]*prp-review-agents v[0-9]|run=[0-9]{8}t[0-9]{6}z-[0-9a-f]+.*pass=|pass=[a-z-]+.*run=[0-9]{8}t[0-9]{6}z-"
```

and in the loop:

```bash
  if [[ "$line" =~ $RUN_RE ]]; then
    IDS+="${BASH_REMATCH[1]}"$'\n'
  elif [[ "${line,,}" =~ $SHAPE_RE ]]; then
    echo "error: cannot parse a review footer — round count unknown, refusing" >&2
    exit 2
  fi
```

Update the header comment's Invariant (lines 4-8) to the Invariant above in 3-4 lines, including the out-of-scope
sentence. Nothing else in the file changes. RUN_RE is unchanged.
